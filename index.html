Data Extraction — Example

# Load results and compute EBITDA margin
import pandas as pd

def compute_ebitda_margin(df):
    df['ebitda'] = df['revenue'] - df['cost_of_goods_sold'] - df['opex']
    df['ebitda_margin'] = df['ebitda'] / df['revenue'] * 100
    return df[['revenue','ebitda','ebitda_margin']]

Financial Formula

Present value of cash flows (discounted cash flow):

\[PV = \sum_{t=1}^{T} \frac{CF_t}{(1+r)^t} + \frac{TV}{(1+r)^T}\]
Explain variables: CF_t = cash flow at time t, r = discount rate, TV = terminal value.
